## JavaScript WebSocket Server

You can test this template:
1. Clone the project and run `npm install`
2. Navigate to `packages/templates/servers/websocket/javascript` and run `npm run test:integration` to generate the WebSocket server
3. Navigate to the generated server with `cd test/temp/snapshotTestResult/server_hoppscotch`
4. Install dependencies of the generated server: `npm install --no-workspaces` (without the flag, npm installs the whole repository instead)
5. Start the server generated by the test: `npm start`

> By default the server listens on port 80. Set the `PORT` environment variable to use another port, then connect with any WebSocket client at `ws://localhost:<port>/`.
